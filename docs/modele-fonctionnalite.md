# Modèle de fiche fonctionnalité

Copier ce bloc dans le cahier des charges pour détailler une fonctionnalité.

---

### F-XXX-00 — Titre court de la fonctionnalité

- **Priorité** : M / S / C / W
- **Statut** : À valider
- **Acteur(s)** : qui utilise cette fonctionnalité ?

**Besoin** — En tant que *<acteur>*, je veux *<action>* afin de *<bénéfice>*.

**Description** — Ce que fait la fonctionnalité, en langage métier.

**Règles de gestion**
1. …
2. …

**Critères d'acceptation**
- [ ] Étant donné …, quand …, alors …
- [ ] …

**Dépendances** — autres fonctionnalités nécessaires (`F-…`).

**Questions ouvertes** — points à trancher.
